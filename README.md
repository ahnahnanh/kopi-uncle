# ☕ Kopi Order Master

A silly kopitiam game. Decode Singlish kopi orders ("Kopi O kosong peng!", "Teh C siew dai tapau!") and survive the 2-minute morning rush before 3 customers walk off.

- Pure static site: just `index.html`, no build step
- Deploy: import this repo in Vercel and leave all the defaults (Framework: Other)
